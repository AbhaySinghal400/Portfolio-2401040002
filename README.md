# Personal Portfolio Website

Mini Project 1 - Web Technologies

## Technologies
- HTML5
- CSS3

## Features
- Semantic HTML5 structure
- Responsive design with media queries
- CSS Grid and Flexbox
- Hover effects
- CSS animation and transitions
- Education table
- Skills and projects sections
- Contact form
- GitHub and LinkedIn links

## How to customize
1. Open `index.html`.
2. Replace "Your Name", college, education, projects, email, phone, location, etc.
3. Replace the GitHub and LinkedIn placeholder URLs with your real profiles.
4. Replace `images/profile-placeholder.svg` with your own profile photo if desired, and update the image `src` in `index.html`.
5. Open `index.html` in a browser to test the website.

## GitHub submission
Upload the complete `portfolio` folder to a new GitHub repository and submit the repository link through the Google Form.
